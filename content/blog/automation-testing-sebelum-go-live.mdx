Bug setelah go-live itu mahal — baik uang maupun reputasi. Karena itu, di Akusara
Digital, **tidak ada produk yang kami rilis tanpa automation testing**.

## Stack testing kami

### E2E: Playwright + Cypress

Untuk simulasi user nyata (klik, isi form, checkout), kami pakai:

- **Playwright + Pytest** — 37+ test case lintas browser
- **Cypress** — 23 kasus untuk flow kritikal

### API Testing

40+ test case yang langsung pukul endpoint. Pastikan response, status code, dan
validasi payload benar sebelum user menyentuhnya.

### Performance: k6

Berapa user maksimum sebelum aplikasi melambat? k6 kasih jawaban konkret — bukan
tebakan.

## Kenapa bukan manual testing saja?

Manual testing itu **penting** untuk exploratory. Tapi untuk regresi (fitur lama
tidak rusak saat tambah fitur baru), manual itu lambat dan rawan lupa. Automation
jalankan 60+ test case dalam menit, setiap deploy.

## Hasilnya?

- Bug setelah go-live turun signifikan
- Deploy lebih sering karena percaya
- Tim QA fokus ke eksplorasi, bukan repetisi
